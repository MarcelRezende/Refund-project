# 💸 Refund — Sistema de Solicitação de Reembolso

Aplicação web desenvolvida para facilitar o registro e o gerenciamento de despesas, permitindo que o usuário adicione solicitações de reembolso, categorize gastos e acompanhe os valores registrados em uma interface simples, intuitiva e responsiva.

## 📸 Preview do Projeto

<img width="1334" height="654" alt="image" src="https://github.com/user-attachments/assets/d74e45ad-59cb-4c13-8339-b8a184c18386" />


O projeto apresenta uma interface moderna, com design minimalista, tons suaves e destaque para a usabilidade.

**Principais elementos da interface:**
- Formulário para cadastro de despesas.
- Campo para informar o nome da despesa.
- Seleção de categorias.
- Campo para inserir o valor da despesa.
- Listagem das solicitações adicionadas.
- Exibição da quantidade de despesas e do valor total.

## 🚀 Tecnologias Utilizadas

- **HTML5:** estruturação semântica da aplicação.
- **CSS3:** estilização da interface, layout e responsividade.
- **JavaScript:** manipulação do DOM, validação de dados e interatividade.

## 🎯 Objetivo do Projeto

O objetivo é praticar os fundamentos do desenvolvimento front-end, trabalhando com estruturação de páginas, estilização, eventos JavaScript, manipulação de elementos HTML e atualização dinâmica de informações.

O projeto também simula uma situação comum no ambiente corporativo: o registro e o acompanhamento de despesas para solicitação de reembolso.
